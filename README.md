Delhi’s air quality remains one of the biggest environmental challenges, so I decided to explore the data behind it. Using Power BI, I created an interactive dashboard that captures how AQI changes across seasons, locations, and pollutants.

🔍 Project Highlights

✔ Processed AQI datasets from CPCB/Delhi govt
✔ Designed visuals for PM2.5, PM10, NO₂, CO & SO₂ levels
✔ Analyzed daily/weekly/monthly AQI trends
✔ Used DAX to build KPIs and forecasting metrics
✔ Added drill-downs for area-wise air quality

📈 Major Insights

AQI worsens drastically during Oct–Jan

PM2.5 contributes the most to unhealthy air

Some zones show consistently hazardous levels

Stubble burning + winter inversion directly influence spikes

🎯 Skills Improved

Power BI, DAX, Data Cleaning, Environmental Analysis, Storytelling with Data
